# 역정보 출처

서울특별시 서울 열린데이터광장, 「서울시 지하철 실시간 도착정보」(OA-12764)의 `실시간도착_역정보(20260902).xlsx`를 기준으로 `lines.js`의 역 이름과 API 역 ID를 구성했습니다. 공공누리 제1유형(출처표시).

원본: https://data.seoul.go.kr/dataList/OA-12764/A/1/datasetView.do

현재 역명 표시를 위해 자양(기존 뚝섬유원지), 평택지제(기존 지제)를 표시명으로 구분했습니다. 4호선 진접·오남·별내별가람은 이름으로 추가했습니다. API 요청명과 화면 표시명은 분리합니다. 실시간 정보 제공 여부는 서울시 API 응답에 따릅니다.

분기 노선은 별도 구간으로 표시합니다. 6호선 응암 순환은 단방향이며, 목적지 추천은 선택 구간 안에서만 계산합니다. 전 노선 환승 경로 탐색은 포함하지 않습니다.

1~9호선 외 경의중앙선, 공항철도, 경춘선, 수인분당선, 신분당선, 우이신설선, GTX-A, 서해선, 경강선의 공식 역정보를 포함합니다. GTX-A는 운정중앙–서울 / 수서–동탄을 분리해 표시합니다. 서해선·경강선은 도착정보만 제공하며 위치 API를 호출하지 않습니다.

## 급행 정차역

`express-data.js`는 코레일 공식 시간표에서 열차번호별 정차/통과를 추출한 자료입니다. 원본 XLSX는 내려받아 `data/korail-*.xlsx`에 보관하며 Git에는 포함하지 않습니다. 재생성: `python tools/build-express.py` (openpyxl 필요).

- 코레일 공식 게시 목록: https://www.korail.com/com/userBoard.do?mode=list&schBcid=ticketTable
- 경의중앙선·경춘선 평일, 2026-09-01 시행: https://www.korail.com/file/cubedata/COMMON/jfile/202608/28/202608281a045c7905b490.xlsx
- 경의중앙선·경춘선 휴일, 2026-09-01 시행: https://www.korail.com/file/cubedata/COMMON/jfile/202608/28/202608281a045c7cc64640.xlsx
- 1호선 평일, 2026-09-01 시행: https://www.korail.com/file/cubedata/COMMON/jfile/202608/28/202608281a045c6bb40560.xlsx
- 1호선 휴일, 2026-09-01 시행: https://www.korail.com/file/cubedata/COMMON/jfile/202608/28/202608281a045c713b2610.xlsx
- 4호선, 2026-08-22 시행: https://www.korail.com/file/cubedata/COMMON/jfile/202608/21/202608211a02345bad7920.xlsx
- 수인분당선, 2026-08-22 시행: https://www.korail.com/file/cubedata/COMMON/jfile/202608/21/202608211a02345f4b6660.xlsx
- 9호선 16개 급행 정차역: 서울시메트로9호선 열차이용안내 https://www.metro9.co.kr/kor/sub01_04.do (2026-10-26 확인).

코레일 원본의 역별 두 행 중 첫 행은 도착, 두 번째 행은 출발/통과 시각입니다. **중간 역에 두 번째 행 시각만 있으면 정차로 처리하지 않습니다.** 시발역의 출발 시각은 예외입니다. 줄임 역명은 공식 역정보와 대응시켰고 비여객 운전 지점(마전·시흥연·시흥기)은 제외합니다.

빨간 실선은 해당 운행일 시간표에서 그 역을 경유하는 급행들이 정차하는 역, 빨간 점선은 일부 급행만 정차하는 역입니다. 경의중앙선은 경의 구간/중앙 구간/서울역 지선의 급행 정차 패턴이 다르므로 노선 전체의 정차역 합집합으로 개별 열차의 정차 여부를 판단하지 않습니다. 실제 상세목록은 열차번호와 종착역까지 대조합니다. 예: 5708은 수색 통과, 5852/5854는 수색 종착 정차.

평일/휴일은 구분하며 주말에는 휴일을 기본 선택합니다. 공휴일에는 화면의 급행 기준을 토·일·공휴일로 선택해야 합니다. 운행표 개정 시 이 자료를 재생성해야 합니다. 임시 운행/미등록 급행은 정차 여부를 추정하지 않으며, 확인되지 않은 급행을 위치정보만으로 도착목록에 추가하지 않습니다. 일반열차 보완은 최신 위치정보의 경로와 종착역을 확인한 경우에 한합니다.

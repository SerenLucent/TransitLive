# 역정보 출처

서울특별시 서울 열린데이터광장, 「서울시 지하철 실시간 도착정보」(OA-12764)의 `실시간도착_역정보(20260902).xlsx`를 기준으로 `lines.js`의 역 이름과 API 역 ID를 구성했습니다. 공공누리 제1유형(출처표시).

원본: https://data.seoul.go.kr/dataList/OA-12764/A/1/datasetView.do

현재 역명 표시를 위해 자양(기존 뚝섬유원지), 평택지제(기존 지제)를 표시명으로 구분했습니다. 4호선 진접·오남·별내별가람은 이름으로 추가했습니다. API 요청명과 화면 표시명은 분리합니다. 실시간 정보 제공 여부는 서울시 API 응답에 따릅니다.

분기 노선은 별도 구간으로 표시합니다. 6호선 응암 순환은 단방향이며, 목적지 추천은 선택 구간 안에서만 계산합니다. 전 노선 환승 경로 탐색은 포함하지 않습니다.

1~9호선 외 경의중앙선, 공항철도, 경춘선, 수인분당선, 신분당선, 우이신설선, GTX-A, 서해선, 경강선의 공식 역정보를 포함합니다. GTX-A는 운정중앙–서울 / 수서–동탄을 분리해 표시합니다. 서해선·경강선은 도착정보만 제공하며 위치 API를 호출하지 않습니다.

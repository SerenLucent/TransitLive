# Transit Live

수도권 18개 노선의 실시간 열차 위치와 역별 도착정보를 표시합니다. 서울시 API를 Apps Script 공유 캐시를 통해 조회합니다.

## 실행

프로젝트 폴더에서 `node serve.cjs` 실행 후 `http://127.0.0.1:5173`에 접속합니다. 빌드나 패키지 설치는 필요하지 않습니다. `index.html`을 직접 열어도 동작합니다.

## 구현

- 호선별 색상, 역 목록, 실제 열차 위치와 열차번호
- 화면 너비에 맞춰 여러 줄로 접는 노선도, 지선 구간 선택
- 역 선택, 부분 이름 검색, 검색 결과 선택 시 스크롤
- 선택한 역의 이번/다음 열차 도착 안내
- 목적지 자동완성과 선택 구간 내 방향 추천
- 페이지가 숨겨지면 새 요청 중단, 6초 자동갱신 카운트다운
- 모바일 가로 스크롤 없이 노선도 표시

`lines.js`는 공식 역정보를 바탕으로 구성했습니다. 분기 노선은 구간 선택으로 표시합니다. 6호선 응암순환은 단방향입니다. 전 노선 환승 경로 탐색은 포함하지 않습니다. 실제 데이터가 없는 역은 미제공 상태로 표시합니다.

`apps-script/Code.gs`를 Apps Script에 저장하고 기존 배포를 새 버전으로 업데이트합니다. 키는 스크립트 속성 `SEOUL_SUBWAY_API_KEY`에 저장하며 프런트엔드에 넣지 않습니다. 캐시는 호선·역별로 분리되어 6초 동안 공유됩니다. 서울시 승인에 따라 자체 하루 900회 차단은 해제했으며 비공개 호출량 집계는 유지합니다. 예약 트리거 없이 요청이 있을 때만 갱신합니다.

검사: `node tests/layout.cjs`, `node tests/live.cjs`, `node tests/backend.cjs`.

서해선·경강선은 도착정보 전용입니다. 열차 위치 조회·아이콘 표시를 하지 않으며 화면에 별도 안내합니다.
